# Workshops for Ukraine — Agentic Coding for R

**Status:** Active
**Description:** Slide deck and skill templates for a Workshops for Ukraine session on adversarial agentic coding for R.
**Authors:** Charles Crabtree, Senior Lecturer, School of Social Sciences, Monash University
**Last Updated:** 2026-04-02

## Structure

- `index.html` — Reveal.js slides (Ukraine-themed palette: blue #0057B8, gold #FFD700)
- `skills/builder-agent/SKILL.md` — Builder skill: numbered R pipelines, here::here(), robust SEs, LaTeX macros
- `skills/reviewer-agent/SKILL.md` — Reviewer skill: adversarial audit, Python verification, stress tests
